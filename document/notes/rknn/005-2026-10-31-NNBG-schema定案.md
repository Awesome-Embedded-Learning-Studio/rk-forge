## 1. 根定位(Q2 闭环,更正 dsh-008)

- 容器:version>=2 → NN_BG 起点 = **model+0x40**(`FUN_002ce000` 0x2ce0bc);
  JSON = NN_BG+exportSize+8(0x756708,算术对到文件尾)
- 标准 GetRoot:`root = fb_base + *(u32*)0x40` = 0xa4;首 i32=0x2c 回指 vtable@0x78
- 0x44 的嵌套 RKNN 头是 version<2 遗留头,不存根位置;0x70..0x77 只是 padding

## 2. 六张表字段速览(全表见 .claude/rknn/dsh-009-nnbg-schema.md §2)

| 表 | 字段数 | 关键字段 |
|---|---:|---|
| root | 20 | f2=子图、f4=**563 blob 池**、f6=版本 0x2904、f14=max_task_shift("0")、f19={池起点,internal 尺寸,0} |
| graph | 7 | f0=tensors(562)、f1=ops(57) |
| tensor | 19 | f2=kind(**7=指令模板**/4=权重/1,2=IO/3=激活)、f12=分配字节、**f18=blob 下标** |
| op | 10 | f4/f5=输入/输出 tensor 索引、**f6=vector<edge>**;六组方案向量挂 op 对象 +0xa0..+0x118 |
| edge | 11 | **f0=主 tensor(模板源)**、f3=enable_mask、f4=int_mask 原码、f6=core_index、f8=core_num(路由) |
| blob | 1 | f0=byte vector |

路由:edge f8(1/2/3)×f6(0/1/2) → A(+0xa0)/B0,B1(+0xb8,+0xd0)/C0..C2(+0xe8,+0x100,+0x118)。

## 3. 两个闭环公式

**gem1(权重+模板池)**:
```python
cur = 0
for i in range(563):            # root.f4 全量,含空 blob 占位
    gem1_off[i] = cur
    cur = (cur + len[i] + 0x3f) & ~0x3f
# 本模型 cur = 0x731bc0 = gem1 实测大小;blob168 → 0x6d0e40 = regcfg_off 域起点
```
**task 行数**:max_task_shift(root f14)="0" → nsub=1 → 每 edge 每 lane 一行;
561 = 82×3(A) + (68+68+1)(B) + (59×3+1)(C)。

## 4. 对 dsh-008 的更正

1. 模板源索引 = **edge+0x90**(f0),不是 +0x94(那是次 tensor,本模型恒 0)
2. 六组方案向量在 **op 对象**,非 edge 对象
3. op1 的 5 行 = 5 条 edge(nsub=1),非"nsub=4+1"
4. PC amount 模式位 = **mode<<16**(B=0x1003f,C=0x2003f),非 0x1000/0x2000
5. 根定位标准 GetRoot(见 §1)
