# 007 — 用户表面收官:query 全表面 + IO 格式变换全对齐(dsh-011)

> 一句话:引擎在 fp16+int8 双模型上,除 byte-exact 装配外,把**用户可见的全部表面**
> (16 条 rknn_query、输入/输出格式变换含定点量化和 NC1HWC2 打包)与 vendor
> 逐行/逐字节对齐——软件侧「能替代」证据链闭合,只剩真板验证。

## 1. 三验收(全部亲手复跑)

1. **query_sweep**(16 条枚举+index 扫参,fp+i8 双模型):应答行与 vendor **0 差异**
   (唯一时变量 run_duration 归一化后)
2. **io_probe 输入变换抽查**:fp 模型 f32 输入→fp16 GEM(301056B)、i8 模型 f32
   随机→int8 GEM(150528B)均 **byte-exact**;dsh-011 自测矩阵更全(f32/f16/u8/i8 ×
   计数/随机/含 NaN/Inf × mean/std 变体 × C=16 模型验 NC1HWC2 打包,见其报告)
3. **replay 回归**:fp+i8 六 GEM 双 PASS

## 2. query 表面的数据源(全部模型内,无硬编码)

| 字段 | 来源 |
|---|---|
| type | io tensor f0(10=fp16→1,3=int8→2) |
| fmt | 输入=根表 f12 layout;输出恒 3(UNDEFINED) |
| qnt_type | 恒 2(fp 模型也报 2) |
| zp / scale | io tensor **f11[0] / f10[0]**(f8/f9=min/max) |
| dims | 输入按 f12 重排 NHWC;输出用 f4 逻辑 shape |
| MEM_SIZE | w=根表 **f19[0]**(池起点=纯权重)、int=f19[1]、dma=六 GEM 和 |
| 错误码 | q12→-1,q13-15→-6(静态),index 越界→-5 |

## 3. IO 变换的实证规则(dsh-011,要点)

- **输入**:f32/f16/u8→fp16 走 `(x-mean[c])/std[c]`→half(RNE);→int8 走
  **16bit 定点乘子管线**(vendor FUN_00317418:`inv_d=(1/std)(1/scale)` double、
  `offset=lrint(zp-inv_d*mean)`、shift=14-log2、`fmaf(mult,x,offset<<shift)`→
  double 除→`frintx`→fminnm/fmaxnm→fcvtzs)——少一步或把除法留在 f32 都会在
  xn.5 差一个量化级;编译加 **-ffp-contract=off** 防收缩
- **NC1HWC2 打包**:`dst=(((n*C1+c/C2)*H+h)*W+c%C2`,C=16 模型(f3=[1,2,8,8,8])
  对拍验证
- **rgb2bgr 在 1.5.0 runtime 是 no-op**(用 quant_img_RGB2BGR 专门转模型实证:
  通道 0 仍用 mean[0]/std[0])——只解析不执行,与 vendor 对齐
- **uint8→int8 直拷条件=tensor 有 f20**(实测 C=3 有/C=16 无);int8→int8 恒直拷
- pass_through=1 拷 native 字节数(非 in.size);不支持 layout 返回 0 不写 GEM
- 输出 want_float=1:fp16→f32、int8→`(q-zp)*scale`

## 4. 顺带修的与顺带发现的

- **MEM_DESTROY ioctl 号纠错**:vendor 用 16B(0xc0107204,内核头
  handle+reserved+obj_addr),我们误写 32B——真内核会拒,已修
- vendor init 期有 ACTION 20/21(POWER_ON/OFF)与 19/22/23 序列,引擎暂不发
  (桩下无感)——**烧板日对照项**,若板上有 pm runtime 问题优先查这里

## 5. 边界(收官后的诚实账)

- 软件侧已覆盖:装配(byte-exact)+query 全表面+IO 变换,oracle=vendor 同装置差分
- 未覆盖:**真板 HW 验证**(唯一硬门槛);动态 shape(1.5.0 toolkit 造不出 oracle,
  留 2.x);多输入/输出模型与 C=16 的 query native attr 面(dsh-011 §7 注)
