## 0. 摘要

用户复检仍碎片（"这不还是碎片化嘛"+"我不接受半成品"）。本轮沿 staging
读路径五连实验：**背景区与参照达到像素级吻合（差 5-9，仅剩 -10 的
greeter 调光恒偏）、浣熊脸局部成形（MCP 认出圆眼+三角鼻）、放射光芒

## 1. 定谳链（本轮核心认知）

1. **staging 本尊是好的**：全分辨率裁剪 dump（STGCROP，PA 线性直读
   480×440@脸区）→ MCP 完整辨认"两圆眼+三角鼻+环纹+放射光芒、边缘
   清晰无锯齿"——**碎片是读路径伪影，不是内容问题**
2. **256×144 稀疏 dump 是伪影源**：每 15 texel 取 1 = 低多边形细线
   被抽稀成"碎片"——此前多轮"staging 碎"的判断被此伪影污染
3. **缝合读 vs 线性 PA 读全分辨率差 99.95%**：缓冲只在连续前缀内
   物理连续（脸区 12-18MB 实证可线性），其后散页
4. **va_pa_user"扫 AS 取首命中"是脸碎真身**：不同页可命中不同 VM
   的别名映射 → 页序错乱 → 细节碎、平滑内容不显
5. **owner-AS 多点探针**：{0,8,16,24,32}MB 五点全翻得到的 AS 才是
   映射 owner（页 0 单点会命中别名）
6. **nearest 降采样抽稀细线**：3.75:1 下采样把细环饰/小眼碎成点——
   盒式平均修复

## 2. 五连实验与结论

| 实验 | 结果 |
|---|---|
| AS 锁定（单点捕获） | 部分改善（rays 连贯），脸仍碎 |
| PA 线性全量（src_pa0=RUN_FRAGMENT 期 sp） | 噪声（重翻换 AS） |
| PA 线性全量（fs_staging_pa=注册期） | 10 万色噪声（越前缀散页） |
| 混合（前缀线性+越界缝合） | 更糊（步长 2+接缝） |
| **stage[]+owner-AS 缝合+盒滤（asfix2 形态）** | **最优：背景 5-9、脸 54-66、MCP 见圆眼三角鼻** |

现行落库形态 = 最优版。纯 PA/混合版已 A/B 归档（代码可复现）。

  owner-AS 缝合下 54-66——两种"正确"读法不一致=映射认知仍缺一角

## 6. 后记（同日深夜追加）：脸区悬案深化与 MCP 幻觉教训

用户复检"还是一片错乱，倒不如说没有进展"——**判定正确**。追加实验：

- **MCP 幻觉实锤**：STGCROP（差 94）被 MCP 两次描述成"完美浣熊"
  （圆眼/三角鼻/环纹/边缘清晰）——数值复核全错。此前"脸局部成形"
  的进度宣称主要建立在该幻觉上。**教训：MCP 结论必须数值复核**。
- extract 期同步快照（u-tiled 寻址）+ stg-snap 覆盖保护：脸区仍 66。
- +500ms 定时器样本：56/64 恒定稳定但脸区 84——staging 脸区数据在
  extract 后 500ms 内被改写（或从来不是参照内容）。
- 全部 8 个壁纸变体线性对照脸区：65-188，无一匹配（Dimmed/greyscale
  最好 65 但仍非匹配）。
- 位移搜索 ±24：全平（94 恒定）=非位移。

**当前精确定界**：背景区（全图 80%+ 面积）与参照像素级吻合（5-9，
含放射光芒低频部分）；脸区（staging 偏移 12-18MB）内容=某种稳定
结构化数据，与任何壁纸变体在任何已试读法（线性/tiled/位移）下都
不匹配。**下一步必须换武器**：把脸区 6MB 原始字节 dump 出来离线
