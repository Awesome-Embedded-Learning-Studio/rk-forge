## 2. 基建（全部 env 门控，默认关）

| 机制 | 开关 | 内容 |
|---|---|---|
| 帧节拍重绘 | FSQUAD_REPAINT=1 | VOP 60fps tick 里用 BG 重铺当前扫描缓冲+`last_mst=0` 失效 console 缓存（面板只在几何变化时重 decode——否则永远显示旧快照） |
| 屏级快照 | 自动 | rjob 期采样成功→st2 快照进 QEMU 侧缓存；tick 期只写缓存。staging BO 被 mutter 释放后 tick 直读=黑屏的解法 |
| 快照择优 | 自动 | 64 点非黑计数，只接受更好的（渐进上传会变好、BO 释放会变黑） |
| AS 捕获 | 自动 | staging 注册时记 bg_as+bg_pa；tick 期 stitch 走查强制用（自证门：走查复现 bg_pa 才启用） |
| 全缓冲镜像 | 自动 | fullres 遍历 scan_msts 全部近期扫描缓冲逐一铺 |
| 标记注入 | FSQUAD_MARK=1 | 五点纯色=坐标链路取证标准仪器 |
| staging 直采 | 自动 | 线性 ≥1024×768 源 plane 8/8 命中→注册 BG |
| A/B 开关 | FSQUAD_STGTILED/RESNAP | tiled 读 staging（否定：周期噪声）/恒覆盖快照（否定：黑化覆盖） |

## 3. tick 期翻译三连坑（本夜主战场）

1. `va_pa_user`（当前 AS）tick 期任意 → 全 AS 一致性翻译改用
2. 一致性翻译被跨 VM 别名判歧义 → bg_pa 缓存 + bg_as 捕获
3. 捕获错 AS 把好路径带黑 → **自证门**（走查复现 bg_pa 才启用）
另：快照保存条件须测 `&0xffffff`（alpha 位恒 1，原条件恒真=黑快照
入库后永远黑）。
