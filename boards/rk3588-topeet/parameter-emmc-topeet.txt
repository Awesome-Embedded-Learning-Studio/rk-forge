# parameter-emmc-topeet.txt — RKFW parameter for the RK3588 eMMC update.img (GPT layout).
#
# RK3588 boots eMMC (same as rk3568-atk, NOT SPI-NAND like aes): BootROM loads idbloader
# raw @ sector 0x40 (the binman idbloader.img, written by RKDevTool's idb stage — NOT a GPT
# partition), idbloader's SPL loads u-boot.itb from the uboot partition (@0x4000, matching
# mainline u-boot's CONFIG_SYS_MMCSD_RAW_MODE_U_BOOT_SECTOR=0x4000), U-Boot bootm's the
# kernel FIT from the boot partition, the kernel mounts the ext4 rootfs. Three GPT
# partitions → rootfs = mmcblk?1p3 (device number confirmed on hardware; mmcblk1p3 by
# analogy with rk3568-atk, adjust bootargs if the board enumerates eMMC as mmcblk0).
#
# Layout (512 B sectors; simplified from vendor parameter.txt which has misc/recovery/backup
# — MVP needs only uboot/boot/rootfs):
#   0x40          idbloader.img   (raw; binman, RKDevTool writes — not a GPT entry)
#   0x4000  uboot  0x2000  (4 MiB; u-boot.itb ~1 MiB)
#   0x6000  boot   0x20000 (64 MiB; boot.img FIT padded to fill)
#   0x26000 rootfs 0x1000000(8 GiB; Ubuntu GNOME desktop + mesa + linux-firmware +
#                          headroom. FIXED — rkfw-pack's regex can't parse the `-` grow
#                          token → empty partition panic. Enlarge if needed.)
FIRMWARE_VER:8.1
MACHINE_MODEL:RK3588
MACHINE_ID:007
MANUFACTURER: RK3588
MAGIC: 0x5041524B
ATAG: 0x00200800
MACHINE: 0xffffffff
CHECK_MASK: 0x80
PWR_HLD: 0,0,A,0,1
TYPE: GPT
GROW_ALIGN: 0
CMDLINE:mtdparts=:0x00002000@0x00004000(uboot),0x00020000@0x00006000(boot),0x01000000@0x00026000(rootfs)
uuid:rootfs=614e0000-0000-4b53-8000-1d28000054a9
