## 1. Rebase 明细（动了的就两处）

**0001（面板驱动）— API 改名**：v7.2 起 `of_drm_get_panel_orientation()` → 
`drm_of_get_panel_orientation()`（drm_of.h，签名同形）。改调用点 + 补
`#include <drm/drm_of.h>`。不接返回值，纯改名无语义差。

**0002（板级 DT）— Makefile hunk 重织**：v7.3 在 rk3588-tiger-haikou-video-demo.dtbo
之后、toybrick 之前没有变化，但 turing 与 rk3588s-coolpi 之间塞了 vicharak-axon /
vicharak-vaaman2 / youyeetoo-yy3588 等新板 → 补丁尾部上下文失效。重织后插入位不变
（字母序 topeet 落在 tiger-haikou 与 toybrick 之间）。

其余 16 个（FIQ/RK860X/GT911×2/VOP2 dclk/DVFS×3/DSU/AFBC×2/virtio/PD_GMAC/
PHY-GPIO/GMAC-clk/dwmac-rk）零改动落 v7.3.1 —— 印证预审：7.2/7.3 没动我们的重头区域。

**白捡**（无需任何动作）：panthor GEM shrinking + 一波 panthor 修复（7.2/7.3）、
RK3568 SGMII BMCR 修复、RKVDEC m2m 安全修复、HCLK_VO1 显式使能、一批新 rk3588 板 DTS。

## 2. 坑两颗

**dtc 不吃 cell 里的算术表达式**：`mode-ums = <REBOOT_FLAG + 12>;` 直接语法错
（列号指在 `+` 上）。dt-binding 头文件又没有 BOOT_UMS 宏 → 用字面量
`<0x5242C30C>` + 注释交代来历。另：往 dts 追加 SoC 级节点必须包进 `/ { }`，
顶层裸节点（`pmu0_grf: syscon@…`）也是语法错——第一版就死在这。

**kernel.org 直连 0 字节挂死**：depth-1 clone 两轮起包阶段（服务端 pack 生成）
一个字节不吐、无超时无报错，forge 的重试只在进程失败时触发，挂死会永远等。
解法：WSL mirrored 模式下 Windows 侧代理（clash 7897）走 127.0.0.1 直达，
`https_proxy=http://127.0.0.1:7897 git clone …` 5 分钟收工（~193MiB 包 + checkout）。
forge 的 Proc 环境白名单不含 https_proxy（防渗漏，by design）——代理场景裸 git 拉完，
forge 认树即可（target 存在即 skip）。

## 4. 模块零配对问题（为什么 TFTP 新内核可直接配老 NFS rootfs）

kernel.config 全 `=y` 零模块（busybox 无 modprobe 的坑逼出来的纪律），rootfs 树内
无 /lib/modules 依赖 → TFTP 拉什么内核就跑什么内核，NFS rootfs（out/.../rootfs，
rootfs.ext4 的同源树）不需要任何同步动作。

## 5. 板侧验证命令块（TFTP+NFS，免烧录）

u-boot 串口打断 autoboot 后：

```
setenv ipaddr 192.168.50.99
setenv serverip 192.168.50.5
tftp ${scriptaddr} boot-tftp.scr
source ${scriptaddr}
```

scr 内容 = bootargs（console=ttyFIQ0 root=/dev/nfs nfsroot=…/out/rk3588-topeet/rootfs,
vers=3,tcp ip=静态七段）+ `tftpboot ${kernel_addr_r} Image` + `tftpboot ${fdt_addr_r}
rk3588-topeet.dtb` + `booti`。源文件 boards/rk3588-topeet/fit/boot-tftp.cmd，
重生成：`mkimage -A arm64 -O linux -T script -C none -d boot-tftp.cmd …/tftpboot/boot-tftp.scr`。

**验收线**：串口出现 `Linux version 7.3.1-00020-g8a8c79486a31` →
`VFS: Mounted root (nfs filesystem)` → 进 shell 后 `uname -r` 对上 →
显示管线回归（LCD 亮 GNOME）+ `reboot loader` 进 rockusb（notes/123）。
