## 0. 结论(全部 offset 可复现,验收 4/4 抽查通过)

| 项 | 判词 |
|---|---|
| 按键检测在 ddrbin? | **翻案成立:不在**。SARADC(0xfec1xxxx)/GPIO0-4(0xfd8a、0xfec2-5)全 blob 零访问(movz/movk 138 条 + 字面量普查双查)。ddrbin 物理上读不了任何键 |
| §5 的魔数 | **错**:0x5242C303(u-boot 命名空间)全 blob 零出现;真魔数 **0xef08a53c**,寄存器同为 0xfd588080 |
| 下载机制 | ddrbin 是 **TPL 侧 relay,不是决策层**:读软件 tag(0xfd588080==0xef08a53c)+ BROM boot source ID(0xff000010);boot source 非 USB 且 tag 命中 → 返 -1 给 BROM → BROM 进 maskrom;boot source==0xa(USB,即 RKDevTool 刚下载的我们)→ 正常 DDR init,好让 usbplug 服务 LOADER |
| 写方(0xb6c0 写 tag+CRU 复位) | 在 eye-scan 函数(入口 **0x985c**)尾部;**门控 eye_2d_scan_en(param bit23)**;出厂 v1.21 info_2t=0x0d680000(bit23=0)→ **咱们烧的 blob 里写方休眠**;_eyescan_v1.20=0x0de80000(bit23=1)才激活 |
| param 表 | @0x11a30,tag 0x12345678/version 6;638 key 中 218 present;**无任何 download/usb/boot 隐藏参数** |
| 按开关→maskrom 谁决策 | **BROM strap,E1 板测盖棺(2026-11-02)**:按住开关+复位,串口连 ddrbin banner 都没有 → BROM 未加载 idblock 直接 USB 下载;usbplug 是 maskrom 之后的 payload,同样不是决策层 |

## 1. 入口与调用图(dsh-001,已验收)

```
0x00: 自检(bl 0x2c 取 PC,页对齐比对 0xff001000 = 本 blob 载入基址)
0x28: b 0x34 → b 0x1083c(检查器;唯一 xref)
0x1083c → 0x9834(32B BROM boot param 拷贝到 0xff016e88,后包装成 ATAG 0x54410058 转发)
        → 0x5cc(UART iomux)→ 0x10940(timer/cntfrq)→ 0x102c8(UART init)
        → 打 banner → 0x628 → 0x985c(DDR init 顶层,47KB 反编译)
```
120 函数/250 边全部从 0x0 可达,无孤立代码。

## 2. 检查器精确语义(0x1083c,综合我方 dump + dsh 反编译)

`tag==0xef08a53c && boot_id<=0x80 && boot_id!=0xa` → 返 -1(relay 去 maskrom);`boot_id==0xa`(USB)或 >0x80 → 继续 init。0xff000010 取值表(vendor 常量 BROM_BOOTSOURCE_ID_ADDR):0 unknown/1 NAND/2 eMMC/3 SPI NOR/4 SPI NAND/5 SD/8 I2C/9 SPI/**10 USB**。

## 3. 验收记录(铁律:声称必复跑)

- 入口 0x28 `b 0x34`、0x2c-0x30 为 get-PC helper ✓(实dump)
- 0xb3e0 `tbz w0,#23` 门控 + info_2t@0x11a7c 双版本字节值(0x0d680000/0x0de80000)✓
- param tag 0x12345678/version 6 @0x11a30 ✓
- dsh 摘要「0x9834 恒 0」为简写歧义:该函数**返回**恒 0(0x9850 `mov w0,#0`),本体是 boot param 拷贝——正文与反编译正确,仅摘要措辞糙
- 0x5441 批量命中 = ATAG 魔数,非异常
